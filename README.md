# Microplastic exposure and liver gene expression (GSE294180)

BT3041 – Analysis and Interpretation of Biological Data, IIT Madras.

We re-analyse a public mouse liver bulk RNA-seq dataset to ask how oral
polyethylene (PE) microplastic exposure relates to hepatic gene expression, and
whether that relationship differs in a liver already stressed by a
steatohepatitis-inducing diet. The aim is to apply the course's statistical
tools (descriptive and visual statistics, dimensionality reduction, clustering,
hypothesis testing, modelling) to real data, carefully and reproducibly.

**Current phase: 1 – dataset understanding, acquisition, audit and exploratory
analysis.** No differential-expression testing or modelling has been done yet;
that waits for the team to review Phase 1 and set aims and hypotheses.

## Scientific motivation

Microplastics (particles 1 µm–5 mm) are found in human blood, placenta and
liver, and polyethylene is among the most abundant polymers detected in
people. The liver handles absorbed xenobiotics and lipid metabolism, and
metabolic dysfunction-associated steatohepatitis (MASH) is a common, diet-driven
liver disease. Whether microplastic exposure disturbs liver metabolism on its
own, or mainly worsens an already stressed liver, is an open question.

## Dataset

| | |
|---|---|
| GEO series | [GSE294180](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE294180) (BioProject PRJNA1248512) |
| Paper | Jung W. *et al.* (2026) *Spatial transcriptome mapping identifies Ppara-Anxa2 cross-talk in microplastic-induced hepatotoxicity.* **Sci. Adv.** 12(25): eaec8681. [doi:10.1126/sciadv.aec8681](https://doi.org/10.1126/sciadv.aec8681) |
| Organism / tissue | Male C57BL/6 mice, liver |
| Assay | Bulk poly(A) RNA-seq, Illumina NextSeq 2000, 2 × 150 bp |
| Processed data used | `GSE294180_MP_raw_counts_gene_level.csv.gz` (Salmon → tximport gene-level counts) |

The paper also contains 10x Xenium spatial single-cell data (deposited on
Zenodo, not GEO). This project starts with the bulk RNA-seq data only.

### Experimental design (2 × 2 factorial, 8 weeks)

| Group | Diet | Daily oral gavage | n in GEO |
|---|---|---|---|
| CD+Veh | Control diet (Research Diets D09100304, 10 kcal% fat) | vehicle (0.1% Tween 20) | 4 |
| CD+PE | Control diet | 2 mg PE microspheres (10–150 µm) | 5 |
| MD+Veh | MASH diet (D09100310: 40 kcal% fat, 20 kcal% fructose, 2% cholesterol) | vehicle | 5 |
| MD+PE | MASH diet | 2 mg PE | 5 |

Full details, sources and caveats: [`reports/dataset_understanding.md`](reports/dataset_understanding.md)
and [`metadata/study_design.csv`](metadata/study_design.csv).

## Reproducing the analysis

Requires Python ≥ 3.12 (results were generated with 3.14.6) and ~100 MB of disk.

```bash
python -m venv .venv
```

Activate it (`.venv\Scripts\activate` on Windows, `source .venv/bin/activate`
elsewhere), then:

```bash
pip install -r requirements.txt && pip install -e .
```

```bash
python scripts/01_download_data.py
```

```bash
python scripts/02_build_sample_metadata.py
```

```bash
python scripts/03_audit_counts.py
```

```bash
python scripts/04_preprocess_counts.py
```

```bash
python scripts/05_descriptive_eda.py
```

```bash
python scripts/06_pca_clustering.py
```

```bash
python scripts/07_build_walkthrough_notebook.py
```

| Step | Script | Main outputs |
|---|---|---|
| 1 | `01_download_data.py` | `data/raw/*`, `metadata/data_provenance.json` |
| 2 | `02_build_sample_metadata.py` | `metadata/sample_metadata.csv` |
| 3 | `03_audit_counts.py` | `results/tables/audit_summary.json`, per-sample audit, gene annotation |
| 4 | `04_preprocess_counts.py` | filtered / normalised / log matrices in `data/processed/` |
| 5 | `05_descriptive_eda.py` | `figures/eda/`, summary tables |
| 6 | `06_pca_clustering.py` | `figures/pca_clustering/`, PCA and clustering tables |
| 7 | `07_build_walkthrough_notebook.py` | `notebooks/01_phase1_walkthrough.ipynb` (tables + figure links) |

Step 1 checks every existing raw file against its recorded SHA-256 and will not
overwrite a file that has changed. NCBI's download server sometimes refuses
requests for a few minutes. If step 1 fails, wait and run it again.

Run the checks with `pytest` and `ruff check .`. GitHub Actions runs the same
checks on every push and pull request.

## Working conventions

- Raw data are never modified; every derived file says in its name what was done to it.
- Each preprocessing choice is justified in `reports/preprocessing_decisions.md`.
- Substantial changes go through a branch and a pull request. Do not overwrite earlier
  results without the team agreeing.
- Commit generated figures and tables only when they come from committed code.

## AI Assistance, Scientific Responsibility & Academic Integrity

This project used AI tools **extensively**, mainly **Claude Code** (Anthropic, Claude Opus 5.5). Claude Code wrote and ran nearly all of the code, produced the figures, ran the statistical analyses, managed the repository's commits and pull requests, and drafted most of the written reports. AI outputs (results, interpretations, candidate hypotheses and draft conclusions) are treated as **drafts for the team's review**, not as accepted scientific claims.

| AI assistance | Student team responsibility |
|---|---|
| Writing, running and debugging Python/R code and pipelines | Choosing the research problem, dataset and project scope |
| Running DESeq2, pathway, concordance and robustness analyses | Deciding which methods and analyses to adopt |
| Tests, data-integrity checks, sensitivity analyses | Examining and accepting or rejecting computational results |
| Figures, layout and labelling | Deciding what the figures show scientifically |
| Summarising literature, explaining concepts, drafting reports and proposing candidate questions and hypotheses | Adopting hypotheses, interpreting biology and statistics, weighing limitations |
| Presentation and communication support | Final conclusions and all submitted claims |

The final scientific claims and interpretations are owned by the student team. Some team confirmations are still pending (adopted hypotheses, results reviewed, other AI tools used); they are listed in the detailed declaration: **[reports/ai_usage_declaration.md](reports/ai_usage_declaration.md)**.
